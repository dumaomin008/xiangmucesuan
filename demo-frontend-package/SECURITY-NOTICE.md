# 外发安全说明

## 已排除

- 原项目 `.git/` 与提交历史
- 原项目 `.openai/hosting.json` 及其中的内部项目标识
- `node_modules/`、`.next/`、`dist/`、本地缓存和临时文件
- `.env` 与任何真实环境变量
- 完整产品需求、角色权限、统计口径、内部业务资料和原始示例数据说明
- 原型测试脚本与内部开发协作说明

## 已脱敏替换

源原型车辆库存数据中存在真实格式的 VIN、车牌、企业主体、项目关联、融资与抵押字段。外发包未保留这些原始值，已替换为 `DEMO-*`、`示例*` 或其他明确的虚构数据。

客户、项目、联系人和演示登录身份也统一改为“示例/演示”命名。电话号码使用无效占位格式，演示账号以 `demo.` 开头。

## 扫描结论

- 未包含已知 API Key、Token、私钥或数据库连接串。
- 未包含真实 `.env` 文件。
- 未包含生产 API、内网服务地址或真实认证配置。
- 登录仅为前端演示逻辑：密码只校验非空，不进行真实认证。
- AI 代理：`DEMO_AI_API_KEY` 仅允许出现在本机未提交的 `.env` / 进程环境；前端脚本与静态资源不得内嵌任何 Key。未配置时测算与本地解读仍可用。

## 后续开发约束

新增功能不得接入真实生产数据。若确需联调，应另建受控环境，并在交付前重新执行敏感信息扫描。
