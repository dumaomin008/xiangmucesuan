## 4. V2.0 已确认映射

### 4.1 字体

- 常规正文和表格：12px；
- 项目阶段图例、漏斗、项目排行、车辆图例和排行：12px；
- 图表表头、来源、单位和低优先级辅助信息：10px；
- 已上传文件名：14px/600；
- 文件元信息：11px；
- 常规统计单位：12px；
- 紧凑详情统计单位：10px。

### 4.2 表格

- 行横线使用 `#EDF0F4` 或映射后的同义 Token；
- 视觉强度低于控件和容器边框；
- 页面宽度足够时不显示冻结列；
- 只有实际横向溢出时冻结第一列或已定义关键列；
- 冻结状态启停不改变列宽、筛选和选择状态。

### 4.3 图标

- 使用统一 SVG 风格；
- 关键图标必须支持 `file://` 直接打开；
- 不使用外部 CSS Mask 作为关键图标的唯一来源；
- 图标失败不得只剩空背景色块。

### 4.4 资料卡

- 已上传文件名突出，类别标题与状态保持次级层级；
- 指针设备可在 Hover/Focus 显示操作；无 Hover 设备直接显示；
- 卡片视觉规则不改变上传、删除和权限规则。

## 5. 业务与视觉边界

以下属于 Requirements / Business Rules / User Flow，不由 Design Spec 决定：

- “需求”术语及字段含义；
- 已交付数量的数据来源；
- 正数跳转和零值不可点击；
- 车辆与项目的关联入口；
- 跟进字段、项目阶段规则和修改记录；
- 资料类别、必填和权限；
- 角色数据范围。

Design Spec 只规定这些元素的层级、状态、Focus、响应式和可读性。

## 7. 冲突与待治理

- 原型个别库存状态标记仍使用紫色，与紫色禁用规则冲突；本次只更新文档，不修改代码。
- 客户关联项目等少量位置仍可能保留旧“计划”文案，应在下一轮文案 QA 统一为“需求”。
- 车辆管理生产权限和小屏正式支持范围尚未确认。

- 浏览器 100% 缩放；
- 检查 1440px、768px、390px；
- 检查字号、边框、圆角、图表密度和信息层级；
- 检查表格无溢出/有溢出两种冻结状态；
- 检查键盘 Focus 与无 Hover 设备；
- 检查外部浏览器直接打开的图标和资源；
- 检查视觉修改未改变业务规则。
