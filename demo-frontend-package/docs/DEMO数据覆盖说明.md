# DEMO 数据覆盖说明

交付包中的业务数据均为虚构数据，仅用于验证页面、组件和交互状态。

## 项目阶段

- 10%项目导入
- 25%市场尽调
- 50%初审通过
- 75%联合评审通过
- 90%签约落地
- 100%交车/投运

## 项目状态

- 进行中
- 待发车
- 租赁中
- 运营中
- 暂停
- 善后处理
- 已终止
- 储备

## 客户类型

- 正式客户
- 潜在客户

## 车辆可租状态

- 可租
- 在租中
- 维修中
- 整备中
- 待整改
- 预排
- 借出

## 角色视角

- 销售人员
- 大区总监
- 最高管理层
- 系统管理员

后续新增状态时，必须同步补充至少一条虚构 DEMO 数据，并更新本说明。

## 排行图

- 所有排行图或排行列表至少展示 5 个名次。
- 当前项目用车数量排行、牵引车所在地排行、挂车品牌型号排行均提供 5 条虚构数据。
