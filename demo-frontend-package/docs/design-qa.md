# UI Design QA｜2026-09-18 基线

> Design Spec：V2.0  
> 原型：新能源重卡经营平台原型｜UI调整基准版 2026-09-18  
> 状态：规范与文档已同步；已知差异保留

## 已确认视觉结果

- 项目、客户、牵引车和挂车页面沿用蓝色品牌、绿色正向状态、弱边框、小圆角和高信息密度方向。
- 常规正文、项目图表、排行、车辆图例和排行主要文字统一为 12px。
- 项目详情紧凑统计单位为 10px；常规统计单位为 12px。
- 已上传文件名为 14px/600，文件元信息为 11px。
- 表格数据行横线使用浅色 `#EDF0F4`。
- 页面宽度足够时取消冻结列；发生横向溢出时才启用冻结列。
- 项目统计图标已改为内嵌 SVG，可在外部浏览器通过 `file://` 打开。

## 组件检查

- 项目列表：五项统计、阶段分布、累计漏斗、需求排行、状态筛选和数据表。
- 项目详情：需求与交付、项目资料、跟进记录、修改记录。
- 客户详情：客户概览、关联项目、客户资料。
- 牵引车：车型分布、所在地排行、筛选和库存表。
- 挂车：车辆类型分布、品牌型号排行、筛选和库存表。
- 资料卡：已上传、待上传、同步资料、Hover/Focus 操作态。

## 交互外观检查

- 已交付正数使用主题色可点击数字，零值使用普通文本。
- 冻结列只由真实横向溢出触发。
- 状态同时使用文字，不只依赖颜色。
- Focus 样式可见；无 Hover 设备上的资料操作保持可见。

## 已知差异

1. 个别库存状态标记仍使用紫色色值，与 V2.0 紫色禁用规则冲突；待确认状态语义后再映射，当前未改代码。
2. 客户关联项目等少量原型文案仍可能保留“计划”字样，下一轮文案 QA 应统一为“需求”。
3. 当前文档已删除独立阶段变更原因规则，但原型中仍可能残留相关旧字段或校验；需要后续单独做需求一致性回归。
4. 客户参与人字段是否保留仍待确认。
5. 当前保存、导入、上传和关联为会话内模拟，不代表生产持久化。
