## 3. 新旧参数映射

未新增、未删除参与计算的字段。展示分组如下：

| 向导步骤 | 现有字段 |
| --- | --- |
| 基本信息 | 项目名称/客户/经理、方案名称、租赁形式、测算年限、年运营月数、起止日期、方案说明 |
| 运输场景 | 线路名称、装货地、卸货地、单程距离、单趟载重、路段名称；专业模式：线路权重（仍不参与计算） |
| 运营参数 | 车队规模、年运营月数、单车月趟数、载重（可改） |
| 成本收益 | 运价/单位、电价、满载/空载能耗、车辆租赁、司机、维保运营、保险税费、过路/装卸/信息/轮胎；高级：财务税务 |
| 确认测算 | 完整度、validateSchemeInput 的阻断/警告 |

实时产能预览继续调用 `previewSegmentHelpers`。整方案预览调用 `calculateScheme`（`GET /api/calculation-schemes/:id/calculate?preview=1`），不落快照。

**模型差异（按 PRD「保留真实计算逻辑」处理）：**

- 现有引擎没有装卸时间、出勤率、运营效率，也没有「反推车辆需求」。普通模式不展示这些虚构环节。
- 「单趟周期」可视化用装货地 → 距离 → 卸货地 + 单车月趟数，明确说明趟次是直接输入。
- 「年收入/年成本/年利润」= 引擎月度结果 × 方案级年运营月数，不是另一套公式。

## 4. 计算引擎复用说明

- 正式测算：原 `POST /api/calculation-schemes/:id/calculate` → `executeCalculation` → `calculateScheme`，仍固化快照/版本。
- 实时预览：同一 `calculateScheme`，仅序列化为 DTO，不写库。
- 路段辅助指标：原 `previewSegmentHelpers`。
- 敏感性、现金流、对比结果 API 未改计算口径。
- 禁止在页面用 `hours / cycleTime` 一类本地公式替代引擎。

## 5. AI 接入说明

| 入口 | 实现 | 降级 |
| --- | --- | --- |
| 工作台 AI 创建 | 建项目 + AI workspace + 资料 + 尝试 parse | 失败可手动新建 |
| 步骤「AI 检查当前步骤」 | 先跑 `validateSchemeInput`，用业务语言展示阻断/风险 | 大模型不可用时仍可完成检查 |
| 字段「?」 | 静态字段说明（来源/影响），不改参数 | 始终可用 |
| 结果「AI 测算摘要」 | 基于引擎 KPI 的解释文本，数值仍从结果对象读取 | 不依赖 LLM |
| 既有 Copilot 抽屉 | AI 工作区结果页保留 | AI 不可用时确定性测算主链路不受影响 |

AI 建议不会静默写入参数。正式财务结果不会由模型覆盖引擎。

## 7. 核心链路

> 新建项目 → 填参数 → AI 检查 → 正式测算 → 查看结果 → 创建方案 → 方案对比

- 工作台「新建项目 / 创建并进入测算」保持可用。
- 「手动创建方案」保持可用。
- 向导自动保存文案仍为「已自动保存」，刷新可恢复。
- 结果页可「调整参数」「创建对比方案」。
- 对比页可选择 2–3 个方案，复制方案仍走 `copyScheme`，A/B 隔离。

## 8. 已知问题

- 工作台「复制项目」未单独做项目级复制 API，可在方案列表复制方案。
- 普通模式财务税务默认收起，漏填时会在确认页由引擎校验拦住。
- AI 工作台创建后若 parse 失败，用户仍需在 AI 页确认线路；不阻断手动测算。
- 第一阶段未做移动端完整测算；小于 1200px 时侧栏可收起。
- 预览在参数尚未合法时显示「—」，这是校验失败而不是另一套算法。

## 9. 后续生产化建议

- 将 Demo 角色切换改为真实登录与权限服务。
- AI 检查可接入既有 LLM Gateway，输出建议卡（应用建议 / 保持当前值）。
- 对比页的 AI 差异解释可在 Copilot 上按 A/B 输入+结果结构化调用。
- 若业务确认单趟时间参数，再纳入模型并回归，而不是先在 UI 造环节。
- 工作台资料上传建议走对象存储，避免浏览器 Base64 直传大文件。
